## 🎯 Purpose

Express is a Node.js framework that helps us create backend applications and APIs easily.

Without Express, we would have to write much more code using Node.js's built-in HTTP module.

Express provides ready-made functions like:

- app.get()
- app.post()
- app.put()
- app.delete()
- app.listen()

These functions make backend development much easier.

## ❓Does Express Store Data?

No.

Express NEVER stores data.

Its job is only to receive requests and send responses.

Database (MongoDB) stores the actual data.

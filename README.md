# Learning Web Development Projects

This repository contains a collection of HTML, CSS, JavaScript, Node.js, and Express learning projects created for practice and study.

## Project Structure

- Root HTML/CSS practice files for layout and styling exercises
- js/ for JavaScript fundamentals and DOM practice
- nodeJS/ for Node.js module examples
- Express/ for backend and API practice
- MERN Handbook/ for study notes and documentation

## Getting Started

1. Clone the repository.
2. Open the project folder in your editor.
3. Install dependencies if needed:
   ```bash
   npm install
   ```
4. Run the relevant project files or scripts as you continue learning.

## Notes

This repository is maintained as a personal learning workspace and is intended to preserve progress safely in Git.
